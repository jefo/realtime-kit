# Демо на 6 минут

Цель: показать работающий конвейер и UI, а не рассказывать про архитектуру.
Всё локально, без ключей и без интернета, кроме Binance WebSocket.

## Подготовка (за 5 минут до звонка)

```bash
cd Products/realtime-kit
bun install
bun test          # 137 тестов, ~0.3 c
```

Три терминала:

```bash
# 1 — график на своих данных
bun run example:udf
# http://localhost:8585

# 2 — живой Binance → SSE
bun run example:bridge
# http://localhost:8790

# 3 — Svelte-терминал
bun run example:terminal
# http://localhost:5190
```

Проверить, что все порты отвечают. Держать открытыми вкладки: график, UI,
репозиторий.

## 0:00–0:30. Контекст

> «Терминалы ломаются не на графиках. Они ломаются на потоке: подписки,
> реконнекты, форматы бирж, backpressure. Я собрал четыре пакета, которые
> закрывают эту часть. Сейчас покажу три живых сценария.»

Не показывать слайды. Сразу экран.

## 0:30–1:30. График на своих данных

Открыть <http://localhost:8585>.

> «Это не TradingView-виджет. Это UDF-сервер: он отдаёт config, symbols,
> history, time, search. График ходит в `/udf/history` и получает OHLCV в
> секундах. Данные — из `MemoryProvider`, в продакшене сюда подставляется
> Binance, БД или внутренний API.»

Показать вкладку Network: запрос `history`, ответ `{s:"ok", t, o, h, l, c, v}`.

> «Провайдер — это один интерфейс. Меняется источник, сервер и график — нет.»

## 1:30–2:30. UI терминала

Открыть <http://localhost:5190>.

> «Это `terminal-kit`: Svelte 5, без CSS-фреймворка и без библиотеки графиков.
> Таблица, стакан, спарклайн, метрики, статус соединения. Тёмная и светлая
> темы, две плотности.»

Кликнуть по строке рынка — график и стакан переключаются. Нажать сортировку
по 24h. Переключить тему.

> «Компоненты не знают про биржу. Данные приходят снаружи. Всё типизировано,
> 30 тестов на форматтеры, сортировку и математику стакана.»

## 2:30–4:00. Живой Binance → SSE

В терминале 2:

```bash
curl -s http://localhost:8790/rt/health
```

> «Шлюз пустой: ноль сессий, ноль подписок.»

Создать подписку:

```bash
curl -s -X POST http://localhost:8790/rt/subscribe \
  -H 'content-type: application/json' \
  -d '{"subscriptions":[{"topic":"quote","params":{"symbol":"BTCUSDT"}}]}'
```

Скопировать `id` и открыть поток:

```bash
curl -sN http://localhost:8790/rt/events/<id>
```

Через 1–2 секунды пойдут реальные котировки:

```
event: quote
data: {"key":"quote:{\"symbol\":\"BTCUSDT\"}", ... "bid":60164.2,"ask":60164.3}
```

> «Один EventSource на сессию. Внутри — подписки, ограниченная очередь,
> lifecycle: первый подписчик запускает поток биржи, последний — останавливает.
> Вот это и есть та часть, которую обычно пишут три месяца.»

Показать `health`: сессия 1, подписка 1, события растут.

## 4:00–5:00. Код

Открыть `packages/market-ingest/src/connectors/binance.ts` или README.

> «Коннектор — это маппинг payload'ов в один union: quote, kline, funding,
> liquidation. Хаб считает ссылки и раздаёт события. Всё остальное — adapters.
> 137 тестов, включая реконнект и backpressure.»

Показать `npm pack --dry-run`:

> «Пакеты собираются в ESM + `.d.ts`, Svelte-компоненты — через
> `svelte-package`. Готовы к npm. MIT.»

## 5:00–6:00. Оффер

> «Есть три способа это использовать:
> 1. Подключить ваши данные к графику — 2–4 недели.
> 2. Собрать real-time слой: SSE + ingest + кэш — 3–5 недель.
> 3. White-label терминал целиком, уже с UI — 6–10 недель.
>
> С чего начнём: у вас сейчас есть график, стриминг или пока ничего?»

Дальше — вопросы, не презентация.
